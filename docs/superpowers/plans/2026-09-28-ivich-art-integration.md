# Ivich 美术接入计划

**目标：** 使用用户已授权的现行美术，交付可安装的选角、卡图与形态预览资源包。

**实现：** 复制源图到独立 Godot 工程，保存明确版本与 SHA256。由 Godot 4.5.1 导入纹理，AtlasTexture 在显示时裁切头像、为卡图添加透明留白，原始图片不改动。C# 通过 BaseLib 资源路径加载；资源缺失时保持代码包的占位回退。

## 已核查边界

- 82 张现行卡图齐全；B03 为纵图，其余为方图。
- 三形态母版为带灰底的 RGB 图，适用于角色展示和选择预览。
- 透明战斗立绘、动作序列与专用状态图标尚未交付，本轮保留已有战斗场景。
- 透明 Q 版镰刀可用于初始遗物；不导入带标注参考、废案或审图拼图。
