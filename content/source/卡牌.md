# 依维希：卡牌设计草案 v0.4

修订日期：2026-09-27。状态：策划候选稿，尚未制作进游戏，未经实战平衡验证。

本版将穿界统一替换为真实伤害，振奋改为每层增加20%魔法伤害，并以“供给—过牌—维持—终端”重写流派。奖励总池扩为72张，补入战斗内成长、百分比递增、三种X费、牌组构成与状态种类结算。初始／魔法使只有魔力，半龙只有怒气；二相一身仍是1:1资源转化的唯一入口。

规则见 [设计方案.md](设计方案.md)，完整流派组件与示例见 [流派构筑.md](流派构筑.md)。本轮修改前的完整版本已存入Git基线 `bb6a66b`；更早卡池另见 [卡牌-v0.1存档.md](卡牌-v0.1存档.md)。新增数值均为候选，不冒充已平衡。

## 1. 先读这几条

- 初始／魔法使不能获得或持有怒气，半龙不能获得或持有魔力。费用按“能量／魔力／怒气”列出，不能直接代付；只有A01二相一身换形时转化现有库存，原资源清空。
- 资源效果受当前形态限制：非半龙不产怒，半龙不回魔，也不把无效收益自动换成另一种资源。镰柄蓄能、甜甜圈明确写出分形态供给，是直接生成对应资源，不兑换旧库存。
- 带“魔法”标签的攻击、技能、能力都是魔法牌，正常需要魔力；减费后仍保留标签。振奋的魔法伤害倍率为 `1＋0.2×层数`，3层是+60%，不是+3点或逐层复利；武技用力量。怒气龙息属于武技，不暗扣魔力。
- 普通魔法立即生效。只有U17、R01、R03、R12、R14这5张高费大魔法有“吟唱1”，即等待到下一个自己的回合开始才准备完成。
- R02时隙封存生效后，所有魔法改为储存；大魔法仍须先完成吟唱。T03术式解放是0费、保留、打出后回手的控制牌，一次释放全部已储存魔法，不复制、不额外收费。
- 保留距离、冰冻、终焉、振奋；增加常规Buff与负面效果的卡牌来源，而不恢复旧咒印、裂隙、锚点、晶化、血债、逆鳞等独立计数器。单卡的本战成长记录只显示在该牌上，不新增角色资源条。
- 本局成长仍有形态进阶、镰刀铭刻；另允许少量卡牌自身的永久伤害或生命上限收益，不增加第三套经验、熟练度或血脉系统。“永久”均只持续本次爬塔。

### 卡面约定

- 升级栏只写改变部分，未提及的费用、属性和代价不变。
- 配套候选：魔法牌仅初始／魔法使可新打出，原生必需怒气费用的牌仅半龙可新打出；减费至0不解除归属。无专属费用的通用牌不受此限制，形态条件的附加效果单独检查。
- “本回合”增益在实际生效的回合结束时移除；封存中的祝福不提前倒计时。
- “消耗另一张手牌”要求有合法对象；“消耗其余手牌”按实际消耗张数结算。消耗卡牌与移除冰冻层数不是同一种事件。
- 默认治疗、格挡、抽牌与资源收益作用于自己；持续能力默认只持续本场战斗。
- 真实伤害忽略目标的全部伤害修正，包括格挡、护盾、减伤、免疫、坚不可摧的伤害限额以及易伤增伤，不扣除目标格挡或护盾。保留出手侧力量／振奋、距离和卡牌条件修正，仍走正常死亡或阶段流程。负面种类可被卡面公式统计，但易伤不会再额外乘算真实伤害。
- 斩杀只认该牌直接伤害造成的合格击杀；永久成长、复制与形态上限的处理见设计方案。

### 本版四个计数约定

- `N`：本次爬塔的永久牌组中，带魔法标签的实体牌张数；重名牌各算1张，临时生成／复制不算。打出时记录，不受这些牌后来进入弃牌堆或消耗堆影响。
- `S`：自己当前拥有的指定正面状态种类数：力量、敏捷、振奋、人工制品、再生、荆棘，最多6种。正数才算，同名不同来源仍只算1种；格挡、资源、形态与能力图标不算。
- `D`：目标当前拥有的冰冻、终焉、虚弱、易伤、脆弱种类数，最多5种；看种类，不把10层虚弱算10种。`S`、`D`都在效果开始结算时记录一次。
- `X`只指费用栏标出的那一种资源；打出时支付该资源的当前全部，并锁定X。另一种固定费用照付；封存释放、吟唱完成和换形都不重新读取X，也不再次收费。R13允许X=0；R14至少5魔力，R15至少1怒气。

初始牌组为11张：B01打击3、B02防御3、B03至B06各1，再加普通牌C07碎饼时间1。初始支持回魔、失血过牌、不花怒气的治疗、施冰与退远；没有怒气，也不放入必须花怒气才能使用的咬合。

初始形态每战只有3魔力、容量5、没有自动回魔，B03不能被“等一回合就有魔力”替代。B04在初始形态只用于失血过牌与积累进阶条件，不能产怒；C07的治疗不以怒气为前提。B03半龙分支直接产怒，不转换任何已有魔力。

魔法使进阶不改变这些牌。半龙永久进阶可把基础打击替换为龙咬；打击+对应龙咬+。临时换形不重新替换牌组。B05霜线及此前取得的魔法牌不会自动变成怒气牌，半龙期间不能新施放；进阶后的换牌衔接仍需另行设计，不擅自增加整副牌组替换。

| 移位与状态搬运 | 刹那折跃、霜河归流、借位嫁祸 | 位置、冰冻和负面状态各有明确对象，不搬运任意未知Buff。 |
| 手牌组织 | 空间书签、绝对回收 | 抽牌与安排牌顶不同于直接回收指定牌。 |
| 消耗爆发 | 舍弃此岸 | 以真实手牌为代价，不把空仓释放当作免费消耗。 |
| 永久培养 | 食界之镰 | 本局逐次增加卡牌基础伤害，不是终焉指数增长。 |
| 战斗内复用成长 | 断面射线、螺旋猎舞 | 一张按点数、一张按初始基数的百分比递增，依赖回收和再次付费。 |
| 牌组构成结算 | 裂界长吟 | 魔法牌数量进入伤害公式；厚法术牌组要配过牌，不靠临时复制刷N。 |
| 状态种类结算 | 灾厄汇编、万象归刃、横断 | 负面种类决定单点系数，正面种类决定伤害或段数。 |
| 资源倾泻 | 星霜齐落、穹界坠落、暴食龙舞 | 分别花全部能量、全部魔力、全部怒气，X始终记录实付值。 |
| 终焉推进 | 终焉刻痕、终末宣告、终焉帷幕、终末咏唱 | 即时攻击附带、冰系条件、消耗引擎、大魔法各自承担不同任务。 |

### 8.3 流派必须有完整组件

完整表见 [流派构筑.md](流派构筑.md)：分别列出资源来源、过牌／回收、防守或控制、成长方式、普通／罕见级输出与成型终端。不再把“某能力＋一张攻击”直接当作完整流派。

魔法侧包括蓄法齐射、复奏循环、法典重术、霜咒控制与消耗终焉；半龙侧包括血怒连段、回环猎舞、再生壁垒与寒血霜息；多Buff镰刀是共享方向。二相接力只作为先古入口的额外组合，不充当这些普通路线缺组件时的补丁。

## 9. 纸面示例与检查点

以下是指定手牌下的规则推演，不代表游戏测试或稳定抽牌概率。

### 9.1 储存Buff，然后近距释放小魔法

已有时隙封存，当前3能量、5魔力、距离+5、振奋0，敌人足够存活：

1. 打出C21苍白祝祷，花2魔力；增益与抽牌都进入储存，没有立刻拿到3振奋。
2. 打出C14冰针，再花2魔力；两段攻击与施冰一起储存，剩1魔力。
3. 打出非魔法的C01引镰，花1能量，将距离设为-5，并造成 `向下取整(7×4/3)=9` 伤害。
4. 打出T03：先结算祝祷，取得本回合3振奋并抽1；再结算冰针，每段为 `向下取整(4×1.6×4/3)=8`，共16伤害，施加2冰冻。这里假定敌人无格挡与其他修正；冰针本身仍是普通魔法伤害。
5. T03回手，但法库已空，不能再次免费播放。若继续用B06退锋，先按当前近距攻击，再回到+5。

如果先存冰针、后存祝祷，冰针就吃不到这次祝祷；如果用C17代替C01，位移也会排进储存队尾，不能提前给前面的冰针增伤。

### 9.2 大魔法不能靠解放跳过吟唱

已激活封存，上一回合支付2能量＋5魔力打出U17裂界长吟：当时只有“吟唱中”，不能被T03释放。下一回合开始完成吟唱后入库，此时才可调整距离并解放。

若此前用U15消耗一张手牌并支付1能量，可以提前完成吟唱，无需怒气；有封存时仍需T03释放。没有封存时，完成吟唱就自动结算，并使用那个时刻的距离。

### 9.3 同一次治疗分成续航与溢疗

半龙98/100生命、0力量、距离0，已启用凝鳞与血铸且怒气足够：C22恢复6，实际回复2、溢疗4，因此凝鳞给2格挡，血铸给本回合2力量；再加C22自身6格挡，共8格挡。

随后U20环刃因本回合确实回复过生命，攻击4次，每次 `4+2=6`，共24基础伤害。实际回复2没有同时冒充6点溢疗，力量也不会留到下一回合。

### 9.4 终焉收益有来源和代价

魔法使已激活单份R11终焉帷幕+时，C24龙胃消费一张牌，施加2终焉并取得3格挡，龙胃的治疗照常、半龙产怒分支不生效；C24本身没有消耗，因此不会额外再触发一次。

R09消费4张手牌且自身消耗时，帷幕总共观察到5次实际消耗；但R09自己的攻击只有4段，不把自身消耗算为第5段。若R09被封存，自身消耗与消耗手牌的时间可能相隔一回合，收益必须在各自实际发生时产生。

### 9.5 真实伤害、成长与X费

- N=8的未升级裂界长吟，基础为 `18＋4×8=50`；3振奋、距离0时为80真实伤害。目标格挡、护盾、易伤与伤害限额均不改变这80；实际生命损失仍不超过目标剩余生命。
- 同一张未升级断面射线连续真实打出三次，分别记录8、12、16基础伤害；即使全部先封存，也不是释放时三个都读成20。下一场恢复8。
- 螺旋猎舞三次基础伤害是12、18、24；升级版是16、24、32。50%是以原始基础伤害累加的百分点，不是每次把上一次数值乘1.5。
- 用3能量与3魔力打出星霜齐落，固定为3段；之后回能、换形或隔回合释放都不改变段数。
- 用9魔力打出穹界坠落，记录X=9，基础90真实伤害；次回合新获得的魔力不参与这份记录。
- 满血半龙、0力量、血铸已生效，使用4怒气的暴食龙舞且目标足够存活：每段2溢疗各给本回合1力量，伤害依次为3、4、5、6，共18；不是四段都按最后的力量计算。

## 10. 本版仍需试玩的项目

- 形态专属资源、分形态奖励与进阶后的旧牌衔接。半龙不再能靠原有回魔牌维持魔法，不能在测试中沿用旧版双库存。
- 法库是否过度压缩一个回合的输出，以及“护盾也被储存”的代价是否清楚；不先给能力额外增伤或减费。
- 17张能力的密度与启动负担；分别检查流派资源、过牌、维持与终端，不能只测试终端在满Buff下的伤害。
- 半龙的回血、血铸多段、消耗供怒是否有趣，是否能过于轻易拖到满血；这是待验证的强度问题，不宣称已平衡。
- 吟唱只在5张高费大魔法上，观察是否值得等、是否会在小怪战过于笨重；不靠把普通小法术也改为吟唱来强推配套。
- 真实伤害对护盾、减免、坚不可摧限额与易伤的全部绕过，以及阶段转换兼容；百分比振奋与新终端的伤害规模须单独测试。
- 三种X费的实付记录、单卡战斗成长、永久牌组计数和正负状态种类去重；规则明确不等于已经验证引擎接口。
- 终焉固定百分比机制本身就强，检查原生阶段、异常防护、多人归属与斩杀条件，不能把特殊死亡当作跳过游戏流程的接口。
- 控制牌回收、临时复制、永久成长、手牌溢出与封存中的目标选择须在实现阶段单独验证。当前没有修改游戏文件或实现代码。
