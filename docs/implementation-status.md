## A01的获得入口

实际游戏中，欧罗巴斯的 **ArchaicTooth（古老牙齿）** 通过特色起始牌升华流程生成先古牌。BaseLib提供 ITranscendenceCard 接口；本Mod把 **B03镰柄蓄能 → A01二相一身** 注册到这一流程，继承原版的变换、升级和附魔处理。

选择B03作为升华源是原稿未指定处的实现决定。A01不进入普通奖励、不属于初始卡组，也不由R02生成。取得A01后，本局允许两侧卡牌进入奖励；即使之后移除该牌也保留解锁记录。

## 关键时序

- 原实体支付、进入出牌/弃牌/消耗流程一次；封存与吟唱保存效果记录，释放不重新出牌或付款。
- 真实打出锁定基础值、升级、X、永久牌组N和单实体成长；S、D、R06格挡在每份效果开始时锁定。
- 力量、振奋、距离每段读取；每段群体攻击锁定统一出手属性，每段R13先完成群伤再施冰。
- 卡面直接负面与被动附加分开统计。寒潮按冰系攻击/技能完成触发，不观察自身的施冰事件。
- 同开始阶段新建的吟唱不立即推进；临时换形及重复安装能力不刷新回合限次。
- 清场后当前效果允许完成合法治疗、资源和成长收尾，未开始的法库记录和新攻击取消。
- U21保留剩余治疗；R15只保留致死段的治疗。R06治疗按原版伤害结果的实际生命损失计算。

## 验证与兼容边界

自动化覆盖纯规则、异步队列、目录、全卡模型/升级/费用及真实Harmony方法绑定，详见[验证记录](verification.md)。这些结果不能替代游戏内玩法、UI及同步测试。

原版或其他Mod通过附魔/诅咒额外附加的出牌钩子保持原版执行时机；法库封存的是本Mod卡面完整效果。原生重放、先古事件、特殊阶段/复活、手牌溢出、保存/继续及多人同步仍需[游戏验证](playtest-checklist.md)。数值沿用候选策划，尚未实战平衡。

剩余制作内容为正式角色美术、三形态场景/动画、卡图、图标和音效的资源接入及PCK导出。
